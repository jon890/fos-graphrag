# 로컬 임베딩은 Qwen3 Embedding 0.6B를 사용한다

## 맥락

GraphRAG 학습에서 한국어 문서와 질의를 같은 벡터 공간으로 변환해야 한다.
외부 API 키와 호출 비용 없이 기존 Ollama 실행 환경을 재사용해야 한다.

## 결정

LangChain의 `OllamaEmbeddings`로 Ollama의 `qwen3-embedding:0.6b`를 호출한다.
벡터 출력은 향후 Neo4j 인덱스와 호환되도록 최대 차원인 1,024로 고정한다.

## 기각한 대안

- 범용 언어 모델을 임베딩에 재사용하면 임베딩 전용 모델보다 검색 목적에 적합하지 않다.
- 호스팅 임베딩 API는 로컬 연산 부담이 없지만 API 키와 외부 서비스 의존이 필요하다.
- BGE-M3는 검증된 다국어 모델이지만 모델 파일이 더 크고 입력 문맥이 더 짧다.
- 영어 중심의 소형 임베딩 모델은 다운로드가 작지만 한국어 학습 자료 검색의 기본값으로 부적합하다.

## 결과

약 639MB의 모델 파일과 로컬 연산 자원이 추가로 필요하다.
향후 Neo4j 벡터 인덱스는 같은 모델과 1,024차원 계약을 사용해야 한다.

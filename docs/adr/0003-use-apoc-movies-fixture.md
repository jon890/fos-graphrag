# Movies 예제 데이터는 APOC Core로 적재한다

## 맥락

Neo4j Sandbox와 공식 Cypher 문서가 사용하는 Movies 그래프를 로컬에서 동일하게 실습해야 한다.
기존 데이터 손상과 반복 실행에 따른 중복 생성은 피해야 한다.

## 결정

개발용 Neo4j Compose에 APOC Core를 활성화하고 `apoc.example.movies()`로 예제를 적재한다.
해당 절차만 허용 목록과 제한 해제 목록에 등록한다.
적재 명령은 빈 데이터베이스에서만 쓰기를 수행하며 완전한 예제가 이미 있으면 재사용한다.

## 기각한 대안

- 약 40KB의 Cypher 원본을 저장소에 복제하면 외부 플러그인이 필요 없지만 공식 데이터 변경을 직접 추적해야 한다.
- 실행할 때마다 원격 Cypher 파일을 내려받으면 저장소는 작지만 네트워크와 원격 파일 변경에 의존한다.
- 데이터베이스 상태를 확인하지 않고 절차를 호출하면 중복 노드와 관계를 만들 수 있다.

## 결과

로컬 개발 컨테이너 시작 시 Neo4j 버전에 맞는 APOC Core가 활성화된다.
운영 배포를 목적으로 하지 않으며 Movies가 아닌 데이터가 존재하면 적재 명령은 중단된다.

Java Agent Lab

직접 타이핑하며 익히는 LangGraph4j

하나의 “개발 작업 계획 검토 에이전트”를 열 단계에 걸쳐 성장시킨다. 이 가이드는 정답 코드를 제공하지 않고, 지금 작성할 범위와 확인할 개념을 안내한다.

학습 원칙
한 단계에서 새 개념은 하나만 추가한다. 먼저 모델 없이 그래프의 동작을 테스트하고, 구조가 이해된 뒤 Spring AI와 Ollama를 연결한다.

완성할 흐름

요구사항 입력 → 요구사항 정규화 → 요구사항·아키텍처·테스트 관점 병렬 검토 → 검토 결과 병합 → 구현 계획 작성 → 품질 평가 ├─ 기준 미달 → 계획 수정 → 재평가 └─ 기준 충족 → 사람 승인 → 완료

내가 타이핑하고, 가이드는 무엇을 하나

직접 작성한다

상태, 노드, 엣지, 테스트와 설정을 직접 입력한다.

제공된 테스트로 확인한다

테스트는 가이드가 먼저 제공하고, 운영 코드를 직접 작성해 실패한 테스트를 통과시킨다.

막히면 힌트를 본다

완성 코드 대신 확인할 클래스와 질문을 이용한다.

코드를 대화로 리뷰한다

작성한 코드와 오류를 공유하고 개념 중심으로 피드백받는다.

학습 순서

먼저 전체 개념 지도를 읽고, 각 Lesson에서도 개념 학습을 마친 뒤 실습 가이드를 따라간다.

00 · 먼저 읽기

LangGraph4j 개념 지도

State, Channel, Node, Edge가 협력하는 전체 실행 모델을 이해한다.

 01

State와 Channel

공유 상태와 병합 규칙부터 설계한다.

 02

단일 Node

부분 상태 갱신을 반환하는 동작을 만든다.

 03

START와 END

가장 작은 실행 가능한 그래프를 컴파일한다.

 04

여러 Node 연결

노드 사이에서 상태가 전달되는 모습을 확인한다.

 05

조건부 Edge

상태 값으로 다음 노드를 선택한다.

 06

반복과 종료 조건

그래프에 사이클과 명시적 상한을 둔다.

 07

병렬 실행과 Reducer

독립된 검토 결과를 안전하게 병합한다.

 08

Spring AI Node

결정적 그래프에 실제 모델 호출을 연결한다.

 09

Checkpoint와 재개

실행 이력을 저장하고 같은 스레드를 이어간다.

 10

승인과 Subgraph

사람의 결정과 작은 그래프의 조합을 다룬다.
처음 시작할 곳
먼저 00단계에서 전체 실행 모델을 이해한다. 그다음 1단계에서 그래프나 Spring Bean 없이 상태 스키마와 테스트만 작성한다.

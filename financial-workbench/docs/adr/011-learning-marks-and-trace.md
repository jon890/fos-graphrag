## ADR-011: 사용자별 이해 표시를 `KNOWS` 관계로 두고, 근거 따라가기를 서버 API 로 계산한다

- **status**: `accepted`
- **결정**: 사용자가 항목마다 남기는 이해 표시(알아요, 잘 모르겠어요, 공부 중)와 메모는 `(:User)-[:KNOWS {level, note, updatedAt}]->(:Knowledge)` 관계로 저장한다. 본인만 읽고 쓰며 열람자도 쓸 수 있다. 지식 데이터가 아니라 개인 기록이라 revision 과 변경 이력(ChangeEvent)을 남기지 않는다. 항목에서 들어오는 관계를 거꾸로 따라가 조상을 모으는 근거 따라가기는 서버의 `GET /api/nodes/{id}/trace` 하나가 계산한다. 근거 관계(끝 타입에 Document 가 있는 관계)와 개념 관계(끝 타입이 Concept 인 관계)는 따라가는 길에서 빼고 단계마다 근거와 개념으로 붙인다. 상단 탭에 「공부」(`/study`)를 더해 탭은 넷이 된다.
- **대체된 부분**: [ADR-010](010-concept-map-first-screen.md) 의 「상단 탭 셋」 을 넷으로 바꾼다. 나머지 화면 구조는 그대로다.
- **맥락**: 다른 사람이 세운 가설을 볼 때 그 가설이 기댄 근거 노드와 관계를 모를 수 있고, 모르는 부분은 공부할 수 있어야 한다(사용자 요청 2026-10-25). 결정에서 변화까지는 4홉이라 주변 그래프(최대 2홉)로는 한 화면에 보이지 않는다([ADR-009](009-investment-logic-chain.md)). 이해 표시는 사람마다 다르고, 두 사람이 같은 항목을 서로 다르게 이해할 수 있다. 「투자 결정 N개 가운데 M개는 근거를 다 이해함」 처럼 결정마다 모든 조상의 표시를 세야 한다.
- **대안 기각**:
  - 브라우저 저장소(`localStorage`)에 표시를 둔다: 서버 변경이 없지만 기기를 바꾸면 사라지고, 결정마다 조상을 세는 계산을 서버가 할 수 없다. 첫 접속 가이드의 끝낸 기록을 서버에 둔 것과 같은 이유로 버렸다.
  - 지식 노드의 속성(`knownBy` 목록 등)으로 둔다: 표시를 바꿀 때마다 공유 노드의 revision 과 이력이 움직여 다른 사람의 편집과 409 로 부딪힌다. 다른 사람의 표시도 노드와 함께 읽혀 본인만 본다는 규칙을 지키기 어렵다.
  - 웹이 이웃 API(`GET /api/nodes/{id}`)를 단계마다 반복해 부른다: 서버 변경이 작지만 깊이 6 이면 요청이 수십 번이고, 단계마다 근거 상태와 비어 있는 관계, 후보를 웹이 다시 계산해야 한다. 능력 범위는 결정마다 반복해야 해서 요청 수가 결정 수에 곱해진다.
  - 이해 표시를 변경 이력에 남긴다: 이력 화면이 개인의 공부 기록으로 채워지고, 다른 사람에게 보이면 안 되는 기록이 이력으로 샌다.
- **결과**:
  - 얻는 것: 투자 결정 하나에서 변화까지의 근거 사슬과 비어 있는 곳을 한 화면에서 본다. 사람마다 모르는 항목을 공부 목록으로 모으고, 결정마다 근거를 다 이해했는지 센다. 표시를 바꿔도 공유 지식의 revision 과 이력은 그대로다.
  - 감당할 것: `:User` 가 처음으로 `:Knowledge` 와 관계를 가진다. 지식 노드를 도는 쿼리는 이 관계를 타지 않게 해야 한다. 상세 쿼리는 양 끝을 `:Knowledge` 로 묶고, 주변 그래프는 경로 위 관계와 노드의 `archived = false` 조건에서 빠지므로 `KNOWS` 와 `:User` 에 `archived` 속성을 두지 않는다. 이해 표시는 이력이 없어 언제 무엇을 바꿨는지는 마지막 시각(`updatedAt`)만 남는다. 근거 따라가기의 규칙(빼는 관계, 깊이와 노드 상한, 상태 판정)이 서버 코드에 있어 바꾸면 API 를 함께 고친다. 상단 탭이 넷이라 폭 390px 머리글이 더 빽빽해진다.
- **적용 범위**: 저장 모델은 [데이터 스키마](../data-schema.md) 의 「이해 표시」, 계약은 [API 계약](../api-contract.md) 의 「근거 따라가기」 와 「내 이해 표시」, 화면은 [흐름](../flow.md) 의 「근거 따라가기」, 「공부」 가 소유한다.
